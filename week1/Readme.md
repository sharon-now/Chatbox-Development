# Week 1: Pizza Order Bot

## Overview

This repository contains the Week 1 activity for the Chatbots Development course. The project implements a simple rule-based chatbot in Python that guides a user through ordering a pizza.

## Features

- Interactive pizza ordering conversation.
- Allows the user to select a pizza size: Small, Medium, or Large.
- Allows the user to select one topping: Pepperoni, Mushrooms, or Cheese.
- Allows the user to choose a drink: Orange, Coca-Cola, Fanta, or Citro.
- Calculates the total price of the order.
- Asks the user to confirm the order.
- Allows the user to restart the order if they select No.
- Immediately terminates if the user types "bye".
- Written in Python for JupyterLab.

## File Structure

- `Uwineza_Sharon_Week1_Activity.ipynb` - Notebook containing the complete Pizza Order Bot code.
- `README.md` - Project documentation.

## How to Run

1. Open the `.ipynb` file in JupyterLab or Google Colab.
2. Run the code cell.
3. Follow the instructions displayed by the chatbot.
4. Choose your pizza size, topping, and drink.
5. Confirm your order when asked.
6. Type `bye` at any time to exit.
